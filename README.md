# 🎮 Tic Tac Toe Game in C

## 📌 About the Project

This is a simple two-player Tic Tac Toe game developed using the C programming language.

The game is played on a 3×3 grid where two players take turns marking spaces with X and O. The first player to get three marks in a row, column, or diagonal wins the game.

This project is designed for beginners who want to practice basic C programming concepts.

## ✨ Features

- Two-player gameplay.
- Simple 3×3 game board.
- Player 1 uses X.
- Player 2 uses O.
- Automatic player turn switching.
- Checks rows, columns, and diagonals for a winner.
- Prevents invalid and already occupied positions.
- Detects draw situations.
- Easy-to-understand source code.

## 🎯 How to Play

1. Player 1 starts with X.
2. Player 2 plays with O.
3. Enter a position between 1 and 9.
4. Players take turns placing their symbols.
5. The first player to make three matching symbols in a row, column, or diagonal wins.
6. If all positions are filled without a winner, the game ends in a draw.
